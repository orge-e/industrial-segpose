# FlexPose Vision UI Design Archive

This directory preserves the reviewed design system, visual audit and baseline
screenshots used by the formal PySide6 implementation in
`industrial_segpose/ui_qt/`.

## Contents

- `design_system.md`: visual tokens and component rules.
- `design_audit.md`: review findings and migration decisions.
- `visual_refinement.md`: final refinement baseline.
- `screenshots/`: approved reference renders.

The disposable standalone prototype was removed after its layout and styling
were migrated into the production package. Do not add runnable UI code here;
continue implementation under `industrial_segpose/ui_qt/`.

## Run the formal Qt UI

```powershell
.\scripts\start_qt_ui.ps1
```
