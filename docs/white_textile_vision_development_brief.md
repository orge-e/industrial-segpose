# 白色纺织裁片视觉识别与吸取项目开发资料

版本：V1.0  
日期：2026-08-11  
对应开发分支：`codex/white-textile-recognition`  
稳定基线分支：`Pink`

## 1. 项目背景

工业裁剪机直接在白色纺织原材料上裁剪特定形状。裁剪完成后，裁片仍可能停留在原材料原位置，视觉系统需要识别已经完成裁剪的工件，并为吸盘抓取流程提供工件类型、数量、图像中心坐标和旋转角度。

本阶段优先完成视觉算法和人机界面，不包含机械臂运动控制、图像坐标到世界坐标的标定及表面缺陷检测。

## 2. 核心难点

1. 裁片和原材料均为白色，颜色、亮度和纹理差异较小，普通颜色分割容易失效。
2. 裁片未与母料完全分离时，外轮廓主要表现为较细、断续且对比度较低的裁剪缝。
3. 布料纹理、纤维、褶皱、污点、阴影和设备背景可能形成伪边缘。
4. 相机曝光、增益、白平衡及现场光照变化会影响裁剪缝的可见性。
5. 相机随吸盘移动时，拍摄距离、视角、背景和运动模糊会发生变化。
6. 工控机需要在定位精度、模板数量、图像分辨率和实时延迟之间取得平衡。

## 3. 建设目标

系统应实现：

- 在当前画面中识别一个或多个已裁剪工件。
- 输出每个目标对应的模板名称。
- 输出当前画面目标总数和各类型数量，不累计整条产线历史数量。
- 输出每个目标的图像中心坐标 `(x, y)`。
- 输出每个目标相对于模板基准方向的 `0°～360°` 旋转角度。
- 输出匹配分数和识别状态；相似模板无法明确区分时标记为“待确认”。
- 在电脑端工作站显示原图、增强结果、裁剪线或分割结果及最终检测标注。
- 模板库由电脑端统一建立、验证和加载执行。

## 4. 功能边界

### 4.1 本阶段包含

- 白色纺织裁片图像采集。
- 裁剪缝增强和候选区域提取。
- 轮廓重建、模板建立和多模板管理。
- 工件识别、定位、分类、计数和角度计算。
- 电脑端建模、调试、实时检测、结果显示和诊断图保存。

### 4.2 本阶段不包含

- 工件表面缺陷检测。
- 机械臂、吸盘、电磁阀和产线节拍控制。
- 相机坐标到机器人世界坐标的转换。
- 吸取轨迹规划和碰撞规避。

## 5. 总体架构

### 5.1 电脑端

电脑端负责计算量较大且需要精细交互的工作：

1. 读取工业相机或本地图像集采集的原始图像。
2. 显示完整图像处理流水线和中间结果。
3. 自动分割裁片，并允许人工修正 mask。
4. 建立和维护多模板库。
5. 设置每个模板的阈值、角度、尺度及特征模式。
6. 使用多张样本进行离线回归测试。
7. 保存可由工控机实时检测程序直接加载的完整模板库。

### 5.2 现场工控机

现场工控机负责工业相机采集、固定曝光控制、模板库加载、预处理、候选区域提取、模板匹配、结果显示和必要的诊断图保存。模板建立与检测共享同一套算法和数据格式。

## 6. 推荐成像方案

软件算法依赖裁剪缝在图像中产生可测量的像素差异。建议现场优先验证以下方案：

- 固定曝光、增益、白平衡和焦距，禁止检测过程中自动漂移。
- 使用低角度侧光或暗场环形光，使裁剪缝形成稳定阴影。
- 采用均匀、无频闪光源，并遮挡环境杂散光。
- 缩短曝光时间以降低相机随吸盘移动产生的运动模糊。
- 保证相机光轴尽量垂直于布面，减少透视畸变。
- 固定工作高度；高度变化较大时启用有限尺度搜索。

如果裁剪缝在原始图像中完全不可见，则必须先改善照明或裁剪后的物理分离状态，单纯调整软件无法可靠恢复不存在的边界信息。

## 7. 图像算法路线

### 7.1 图像预处理

1. 大图按最长边限制进行等比例缩放，保留原图与处理图之间的坐标比例。
2. 使用中值或双边滤波抑制孤立噪点，同时保留裁剪边缘。
3. 估计低频光照背景，消除阴影和曝光不均。
4. 使用局部对比度增强改善浅色裁剪缝的可见性。
5. 根据现场图像选择黑帽、顶帽、形态学梯度或方向梯度增强。

### 7.2 裁剪缝与候选区域提取

1. 融合亮度梯度、局部暗线和纹理差异响应。
2. 过滤过短、过细或方向随机的纤维噪声。
3. 对断续裁剪线执行受限连接和形态学闭合。
4. 生成一个或多个候选闭合区域。
5. 根据面积、周长、长宽比、闭合度和位置过滤异常区域。

### 7.3 模板表达

每个模板至少保存：

- 稳定模板 ID 和可读模板名称。
- 裁片图像、二值 mask 和有效轮廓。
- 模板中心和基准方向。
- 模板尺寸及允许尺度范围。
- 匹配阈值、角度范围和角度步长。
- 推荐预处理模式及参数。
- 可选吸取参考点，为后续机器人抓取预留。

### 7.4 识别与姿态计算

1. 先使用候选区域降低全图搜索量。
2. 使用轮廓距离、方向梯度或 Chamfer 类特征完成形状匹配。
3. 采用粗角度搜索加局部精细搜索，覆盖完整 `0°～360°`。
4. 对同一目标的重复候选执行模板内 NMS。
5. 对不同模板产生的重叠候选执行跨模板冲突消解。
6. 输出模板名称、中心坐标、旋转角度、尺度和匹配分数。

### 7.5 AI粗定位预留

当传统候选提取受到复杂布纹、褶皱或断裂裁剪缝影响时，可增加轻量 AI 模型完成候选区域粗定位。最终模板类型、中心和角度仍由几何模板匹配确定，以保留可解释性和新增模板的灵活性。

## 8. UI设计要求

### 8.1 电脑端建模界面

- 图像来源：本地文件、工业相机采集目录或视频回放。
- 选择基准图后立即冻结并显示自动分割预览。
- 同时显示原图、增强图、初始 mask、修正 mask 和裁剪轮廓。
- 支持画笔、橡皮、多边形、撤销、重做和重新拍摄。
- 保存后自动加入模板库，不覆盖同名模板。
- 模板库显示名称、状态、尺寸、阈值、角度范围、尺度范围和文件完整性。
- 模板保存后立即写入完整持久模板库，并可直接进入检测验证。

### 8.2 实时检测界面

- 顶部显示当前画面目标总数、FPS 和运行状态。
- 每个目标旁显示模板名称、中心坐标、角度和得分。
- 不同模板使用不同颜色，待确认目标使用黄色。
- 提供原图、增强图、裁剪线、候选区域和最终结果视图切换。
- 支持画面放大、缩小、适应窗口和保存当前帧。
- 发生异常时保存错误日志，必要时保存最近一帧及中间结果。

## 9. 数据采集规范

每种工件建议至少采集以下样本：

- 1 组标准模板图：工件静止、无遮挡、对焦清晰。
- 多个旋转角度：覆盖完整 360°。
- 不同画面位置：中心、四角和视野边缘。
- 不同拍摄高度或允许尺度。
- 正常、偏暗、偏亮和局部不均匀照明。
- 轻微褶皱、毛边、裁剪线断续和局部翘边。
- 空白母料、未裁剪区域和其他工件作为负样本。
- 多工件同框、靠近但不重叠的场景。

原始图像必须保留，不应只保存压缩后的截图或带检测标注的图片。

建议按“工件类型/场景编号/连续序号”组织文件；相机时间不可用时使用采集批次号和递增序号。

## 10. 调试输出

每次离线测试建议保存：

- `01_original`：原始图。
- `02_illumination_normalized`：光照均衡结果。
- `03_edge_response`：裁剪缝增强结果。
- `04_binary_candidates`：二值候选线。
- `05_closed_regions`：连接后的候选区域。
- `06_template_scores`：模板候选与分数。
- `07_final_result`：最终标注图。
- `result.json`：名称、数量、中心、角度、尺度、得分和耗时。

生产模式默认只保留必要日志；诊断模式下才保存完整中间图，并设置目录容量上限。

## 11. 性能与资源约束

- 输入大图必须在检测前缩放，处理完成后将坐标映射回原图。
- 模板变体按需生成并缓存，不在每帧重复计算。
- 限制同时启用模板数、尺度层级和角度步长。
- 检测线程与 UI 刷新解耦，避免长耗时操作造成黑屏或触摸无响应。
- 日志和诊断图采用循环覆盖或容量上限策略。
- 模板库采用单一数据源：删除模板后，后续检测不应继续加载残留资产。

## 12. 阶段开发计划

### 阶段一：成像与数据基线

- 完成实际裁剪机台图像采集。
- 固定相机曝光参数并比较不同照明方式。
- 建立标准数据集和人工标注真值。

### 阶段二：电脑端算法开发

- 实现白布裁剪缝增强模式。
- 实现中间结果保存和参数对比。
- 完成轮廓模板建立及 360°匹配。
- 在固定数据集上评估定位、角度和计数结果。

### 阶段三：工控机实时化

- 接入工业相机 SDK 或 OpenCV 视频源。
- 优化线程、缓存、图像尺寸和模板变体复用。
- 完成实时可视化和错误日志。

### 阶段四：现场验证

- 验证不同工件、位置、角度、光照和移动速度。
- 统计漏检、误检、中心误差、角度误差和处理耗时。
- 固化每种模板参数及相机参数。

### 阶段五：抓取接口预留

- 输出结构化视觉结果。
- 增加吸取参考点及有效抓取状态。
- 为后续手眼标定和运动控制提供接口。

## 13. 建议验收指标

最终指标应在获得实际产线节拍、视野尺寸和机械精度要求后确认。第一阶段建议至少统计：

- 工件检出率。
- 空白画面误检率。
- 当前画面计数准确率。
- 模板分类准确率。
- 图像中心定位误差，单位为像素。
- 旋转角度平均误差和最大误差。
- 单帧平均耗时、最大耗时和最低 FPS。
- 连续运行稳定时间及异常恢复能力。

## 14. 需要现场确认的参数

- 裁剪机台有效视野尺寸。
- 相机安装方式：固定安装或与吸盘刚性连接。
- 相机到布面的正常距离及允许波动。
- 传送带或裁剪台的背景材质和颜色。
- 裁剪缝典型宽度及是否存在物理间隙。
- 工件最小和最大尺寸。
- 同屏最大工件数量及是否允许接触或重叠。
- 吸取节拍、允许视觉处理时间。
- 中心坐标和角度允许误差。
- 是否允许增加侧光、环形光或遮光结构。

## 15. 当前结论

该方案具备可行性，但可靠性首先取决于成像系统能否稳定呈现裁剪缝。项目应采用“成像优化 + 裁剪缝增强 + 轮廓模板匹配”的主路线，并预留 AI 粗定位能力。电脑端负责高质量建模、完整模板库管理和现场实时执行，是当前兼顾效果、可维护性和扩展性的合理架构。

## 16. 当前算法使用方法

电脑端 UI 的模板分割方式和检测特征方式中已经增加“白色裁剪缝”模式。建立模板时先选择包含完整裁片且四周留有母料的 ROI，再选择“白色裁剪缝分割”检查自动 mask；保存模板时将特征方式设置为“白色裁剪缝”。

在正式建立模板前，可使用诊断命令批量检查原始图像：

```powershell
python -m industrial_segpose white-diagnose `
  --input "D:\white-textile-images" `
  --output "D:\white-textile-diagnostics" `
  --recursive
```

每张输入图像会生成独立目录，包含光照归一化图、裁剪缝响应图、二值裁剪线、闭合边界、最终 mask 和 `result.json`。现场图像应优先检查 `03_seam_response.png` 和 `05_closed_boundary.png`：前者用于确认裁剪缝能否被增强，后者用于确认断裂的边界能否闭合。

## 17. 多颜色与多材质统一识别原则

系统采用“候选提取”和“工件分类”分离的架构。颜色、亮度、纹理和裁剪缝只用于从画面中提出可能的工件区域；模板名称必须由候选轮廓与模板库的形状匹配结果确定，不能直接由颜色推断。

模板特征方式设为“智能多模式”时，电脑端根据模板 mask 内外的统计特征自动选择：

- 有稳定色度差异：模板自适应色度候选，即 `pose_tolerant`。
- 浅色工件与浅色母料接近：裁剪缝闭合，即 `white_cut_seam`。
- 暗色工件主要依靠织纹区分：局部纹理候选，即 `dark_textile`。
- 没有可靠颜色、纹理或背景样本：回退到通用轮廓边缘，即 `edges`。

每个模板仍可显式覆盖自动推荐结果。一次多模板检测会创建单帧共享上下文，相同模式的模板复用预处理图和候选 mask，避免模板数量增加时重复执行昂贵的白色裁剪缝或暗色纹理分割。检测结果的 `templates` 字段记录 `resolved_feature_mode` 和推荐原因，模板库保存最终解析后的特征模式，便于现场复现与调试。
