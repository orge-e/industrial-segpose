# 模板匹配与生产工作流

本页整理 Industrial SegPose 中与桌面模板工具、实时生产和多模板管理相关的使用逻辑。README 仅保留入口级说明，具体工作流集中在这里。

## 1. 模板匹配桌面工具

启动：

```bash
python -m industrial_segpose.template_ui
```

该工具用于目标识别、定位、角度测量和计数，不执行表面缺陷检测，也不依赖异常检测模型。

典型流程：

1. 导入参考图像。
2. 自动定位主要目标，或手动框选 ROI。
3. 使用自动分割生成初始 Mask。
4. 在编辑器中使用多边形、画笔或橡皮擦修正 Mask。
5. 保存模板并加入模板库。
6. 在检测图像中设置得分阈值、角度范围、角度步长和可选尺度范围。
7. 执行检测并导出标注图、`results.json` 和 `results.csv`。

对于浅色、纺织或灰白背景目标，可根据现场条件选择 Lab/HSV 色度、GrabCut、Otsu、边缘或纹理策略。自动分割仅用于生成初稿，正式模板应人工复核有效区域。

## 2. 模板几何与角度

模板图像和 Mask 在搜索阶段同步旋转、缩放，Mask 外背景不参与有效区域匹配。

角度表示检测目标相对模板的旋转量，逆时针为正，范围规范化到：

```text
[-180°, 180°)
```

角度精度受搜索步长影响：步长越小，姿态搜索越精细，但计算量也越大。现场姿态范围明确时，应优先缩小搜索范围。

## 3. 多模板工件库

模板由 `templates/template_library.json` 管理。

支持：

- 导入多个工件模板
- 启用 / 停用模板
- 为不同模板配置独立阈值和角度/尺度范围
- 重命名显示类型而保持内部 ID 稳定
- 输出总目标数和按模板分类数量
- 跨模板候选去重与待确认状态

当同一位置存在多个模板候选时，系统会比较归一化得分。最佳与次佳候选过于接近时可标记为“待确认”，便于后续人工复核。

## 4. 实时生产与传送带计数

实时生产页支持 OpenCV 可读取的相机编号或视频文件。

采集和检测采用独立线程：采集侧持续更新最新帧，检测侧独立处理，避免复杂模板搜索直接阻塞 UI。

实时链路包括：

- 欠曝、过曝、模糊和大范围光照不均检查
- 可选质量门控
- 跨帧最近邻轨迹关联
- 稳定 `track_id`
- 横向或纵向计数线
- 正向、反向或双向计数
- 当前目标数、累计数量、分类累计、活动轨迹和处理耗时显示

同一轨迹只累计一次。正式相机建议锁定曝光、增益、焦距、分辨率和安装位置。

## 5. 版本边界

v0.11 起，本仓库聚焦 PC 端工业视觉工作站、数据评估和生产流程，不再维护早期 K230 板端运行时。早期 K230 实验代码与文档保留在 `milestone/pink-textile-stable` 和 `archive/pink-line-before-squash` 标签中，便于追溯研究过程。

## 6. 使用边界

模板匹配适合目标外观稳定、尺度变化有限、相机视角和照明可控的工业场景。

以下情况应优先考虑学习型检测或分割模型：

- 严重遮挡
- 强透视变化
- 大幅尺度变化
- 明显非刚性形变
- 需要依靠语义而非几何/纹理区分目标
